# GK_EXPERT — ассистент протоколирования совещаний

Рабочий прототип для записи или загрузки аудио, локальной транскрипции, подготовки списка поручений и экспорта протокола в DOCX/PDF. Интерфейс — настольное приложение Windows на Python/pywebview.

Репозиторий содержит текущие исходники разработки. Это контрольная точка хакатона, а не заявление о завершении всех требований кейса.

## Запуск из исходников

Требуется Windows и Python 3.11. Выполните в папке проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-local-stt.txt
.\.venv\Scripts\hf.exe download SYSTRAN/faster-whisper-small --revision 536b0662742c02347bc0e980a01041f333bce120 --local-dir models/whisper-small
.\.venv\Scripts\python.exe app.py
```

Установка зависимостей и загрузка публичных весов выполняются до перехода в изолированный контур. В процессе распознавания STT использует локальные файлы модели. Подробности и подготовка изолированной машины: [LOCAL_STT.md](LOCAL_STT.md).

Для сценария хакатона выбирайте **Offline Rule Engine**. Облачные NLP-маршруты, присутствующие в разрабатываемом интерфейсе, не соответствуют запрету передачи аудио/текста наружу. Локальный запуск CLI сам по себе также не означает локальное исполнение модели. До завершения проверки всех маршрутов не используйте чувствительные данные и внешние обработчики.

## Основной сценарий

1. Подготовьте синтетическую запись на русском, казахском или смешанной речи; реальные материалы для демонстрации предварительно анонимизируйте.
2. Загрузите аудиофайл либо выберите микрофон/системный звук и начните запись, уведомив участников.
3. Остановите запись и запустите локальную обработку.
4. Проверьте транскрипт, найденные поручения, исполнителей и сроки; исправьте неопределенные данные.
5. Экспортируйте протокол в DOCX/PDF.

Выбор окна для предпросмотра и захват системного звука — отдельные действия. Звук приложений записывается через WASAPI Loopback выбранного устройства вывода.

## Что проверено

- Микрофон сохраняется в итоговом миксе вместе с системной дорожкой; поддержаны разные частоты и каналы, исключено переполнение PCM.
- Запись подтверждается после открытия устройств; ошибки и пустые записи сообщаются явно, остановка ожидает сохранения файла.
- STT работает через локальный faster-whisper, без облачного fallback и автоматической загрузки весов во время обработки.
- Модуль STT не привязан к конкретной организации; язык задается как `ru`, `kk` или `auto/mixed`.
- 29 изолированных регрессионных тестов аудио и STT выполнены успешно на контрольной точке 23.09.2026.
- Реальное распознавание проверено на двух локальных фрагментах по 30 секунд с запрещенными Python-сетевыми соединениями. Это проверка запуска, не оценка точности RU/KZ/смешанной речи.

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p "test_*.py" -v
```

## Текущие ограничения

- Акустическая диаризация с надежным определением говорящего пока не завершена. Текстовые подписи/догадки об участниках не заменяют диаризацию.
- Локальное извлечение поручений пока использует правила; качество имен, сроков, казахской речи и саммари требует дальнейшей проверки.
- Исправления импорта, выбора окна, интерфейса и EXE интегрируются параллельно. Успешные модульные тесты не означают, что готовая сборка прошла весь пользовательский сценарий.
- Автоматические напоминания и полноценные интеграции с СЭД не подтверждены. Экспорт JSON/XML — заготовка интеграции.
- Часть корпоративных демонстрационных значений и внешних ресурсов интерфейса еще требует удаления/локализации.

## Структура

- `app.py` — настольное окно, локальный HTTP API и связь модулей.
- `core/audio_recorder.py` — микрофон, WASAPI и сведение дорожек.
- `core/stt_engine.py` — локальное распознавание.
- `core/nlp_extractor.py` — извлечение поручений и саммари.
- `core/export_service.py` — DOCX/PDF.
- `ui/` — интерфейс.
- `tests/` — изолированные регрессионные тесты без реальных записей.

Ключи, `.env`, аудиозаписи, транскрипты, пользовательское хранилище, модели и бинарные сборки в репозиторий не включаются. Они остаются локально. Исходная локальная Git-история с секретами не переносилась; удаленная история репозитория сохранена.
