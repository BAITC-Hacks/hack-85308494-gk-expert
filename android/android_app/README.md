# SamrukMeetingAI (Мобильная часть)

Приложение для транскрипции встреч со звука телефона в реальном времени.

## Логика работы приложения:
- **Невидимый старт:** При запуске приложения не открывается полноэкранный интерфейс, появляется только небольшое свернутое плавающее окно (меню) поверх других окон в верхней части экрана.
- **Индикация записи:** В свернутом состоянии присутствует индикатор (лампочка). Если запись включена — горит красная лампочка, если выключена — индикатор не горит. Также есть кнопка включения/выключения записи.
- **Развернутое состояние:** При разворачивании меню открывается окно с текстом.
- **Вкладки (Tabs):**
  1. **Транскрипт:** Сюда вписывается текст, распознанный из звуков телефона в реальном времени. Приложение автоматически подчеркивает/обозначает разных спикеров (Спикер 1, Спикер 2 и т.д.).
  2. **Важные моменты:** В этой вкладке отображаются только ключевые моменты и важные фразы из разговора (хайлайты).

## Стек
- Android Studio
- Kotlin
- Foreground Services & System Alert Window (Floating UI)
- MediaProjection API (Захват системного аудио)
