# QazaqProtocol — локальное приложение Windows

Откройте `QazaqProtocol.exe` внутри папки `QazaqProtocol-Local`.
Сохраняйте рядом папки `_internal` и `models`: это зависимости и модель распознавания.
На другом компьютере копируйте всю папку. Python, API-ключ и интернет для обработки не нужны.
Для окна приложения требуется Microsoft Edge WebView2 Runtime (обычно уже установлен в Windows).
Оформление: строгие графитовые панели, приглушённые синие акценты и Manrope.
Компоновка, история, источники, запись, голоса и экспорт сохранены. Эквалайзер плеера
показывает 40 частотных полос; при паузе и тишине он неподвижен.
В «Настройки → Внешний вид» можно выбрать полосы или пульсирующий круг и изменить
прозрачность окна (непрозрачность от 40 до 100%). Нажмите «Сохранить»: параметры
применятся и останутся при следующем запуске. В браузере прозрачность окна недоступна.

1. В настройках укажите организацию, язык (русский, қазақша или авто для смешанной речи) и необязательный глоссарий.
2. Загрузите MP3/WAV/M4A/OGG/FLAC/WebM/MP4 или начните запись.
3. Для речи из браузера/Zoom выберите «Только Sys Loopback» и устройство, через которое слышите звук.
   Для своего микрофона и собеседников выберите Mic+Sys. Перед записью уведомите участников.
   По умолчанию микрофон выключен. Кнопка микшера включает/выключает его звук;
   при выборе экрана он отключается автоматически. Заглушение действует на новые аудиоданные.
   Выбор окна нужен лишь для предпросмотра экрана; он не требуется для записи звука браузера.
4. Приложение запускается с пустой рабочей сессией. Старые записи открываются только через «История»;
   там указаны дата и время сохранения записи. После обработки новой записи нажмите «Открыть стенограмму».
5. Во время записи «Живая стенограмма» распознаёт фрагменты по 8 секунд в отдельном потоке.
   Одновременно можно загрузить файл: он распознаётся целиком в другом потоке за один проход.
   Текст появляется постепенно; короткие интервалы по 20 секунд служат только для прослушивания.
   Задержка зависит от компьютера; итоговая обработка после остановки включает и последний короткий фрагмент.
6. «Слушать live-фрагмент» и «Слушать обрабатываемый фрагмент» открывают стенограмму
   только указанного интервала с его коротким аудио. Пока фрагмент распознаётся, текст ожидается
   и появляется автоматически. TXT из этого просмотра сохраняет только фрагмент.
   Нажмите «Полностью» для протокола исходного файла. Поручения, ключевые моменты, саммари
   и экспорт Word/PDF/СЭД относятся ко всей записи. До её обработки показывается ожидание.
   Карандаш рядом с говорящим меняет его имя во всех репликах и связанных поручениях.
   Эквалайзер следует звуку
   плеера и замирает на паузе. Плеер не переключает интервалы автоматически.
   При включённом системном канале воспроизведение также попадёт в новую запись.
7. Глаз у источника включает/выключает его звук; замок фиксирует выбор устройства.
   Плюс возвращает источник, корзина убирает выбранный, стрелки меняют порядок, обновление перечитывает устройства.
   Подключить ранее выключенный при старте источник можно перед следующей записью.
8. Word/PDF/TXT и СЭД открывают окно «Сохранить как»: выберите папку и имя. Отмена ничего не записывает
   в выбранную папку. В резервном режиме браузера файл поступает в его загрузки.
   Проверьте текст и поручения перед использованием протокола.
9. Дождитесь окончания фоновой обработки перед закрытием приложения.

Данные, настройки и протоколы хранятся отдельно для каждого пользователя:
`%LOCALAPPDATA%\QazaqProtocol\storage`. Исходные записи не удаляются при обновлении приложения.
Обработка выполняется локально на CPU: первая загрузка модели и длинные записи требуют времени.
Показывается текущий этап, а не выдуманный процент готовности.

Ограничения прототипа: локальный Whisper small; поручения выделяются правилами RU/KK,
поэтому возможны пропуски и неточности. Саммари содержит выдержки из стенограммы.
Голоса разделяются локально. Имена предлагаются по представлениям и обращениям в контексте;
проверьте и подтвердите их в карточках голосов. «Послушать голос» воспроизводит образец.
Известные имена и количество участников можно указать в настройках перед обработкой.
Повторяющийся голос сохраняет метку внутри записи; между совещаниями автоматического узнавания нет.
Одновременная речь, похожие голоса и очень короткие ответы могут остаться неразличёнными.
Старые протоколы обновляются кнопкой «Повторно распознать с голосами» (новая запись в истории).
Протокол и экспорт относятся к выбранному файлу; до окончания его обработки старый протокол не открывается.
Неизвестные ответственные и сроки помечаются явно. Автоподключение к конференциям не реализовано.

Сборка из исходников: установите requirements.txt и PyInstaller в Python 3.11,
подготовьте модель по LOCAL_STT.md и `python scripts/prepare_speaker_models.py`, выполните `python build_portable.py`.
Результат: `dist\QazaqProtocol-Local\QazaqProtocol.exe`.
